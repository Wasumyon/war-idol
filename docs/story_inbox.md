# Story inbox

Story ideas that came up while building. Any agent adds to this file; only Claude, in a story
chat with Wesley, sorts entries into the decisions log and deletes them from here.

Format: `- YYYY-MM-DD (while working on …): the idea, in Wesley's words.`
- 2026-11-16 (while planning the tunnel port): "it would be an interesting idea for each pause menu in each game to be different, like losing access to dossiers while in the pit".
