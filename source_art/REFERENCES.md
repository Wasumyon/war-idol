# Visual references for image generation

Before generating any War Idol image: find the subject below, attach its **Attach** files as
reference images, and paste its **Prompt** line into the prompt. Add its **Never** line as a
negative. Save the result to **Save to**. Paths are relative to `source_art/`.

Who a character *is* lives in canon (`docs/canon/`); this file is only how things look.
**A file not listed here is not a reference** (old drafts, studies, sketches, superseded versions).
When a sheet changes, update its entry here; never copy images to make a reference set.

House style for character sheets: clean anime production sheet, cel shading, flat light-grey
background, labelled views (front / 3/4 / side / back), expression row, detail callouts, palette swatches.
