# War Idols — Tunnel Escape (prototype)

Godot 4.7.2, GL Compatibility, 1280×720. Design: `design.md`.
Game jam submission deadline: **Oct 30, 2026**.

## Status (updated 2026-10-27, 03:05)
- **Chamber 1 is playtested and works** in the editor: movement, lamp, tubeworms, checkpoint,
  death/respawn, exit.
- **Tuning done after playtest:** player speed +30% (max_speed 221, accel/decel scaled with it).
- **Tubeworm rule (decided):** grown worms in the dark are a solid wall; brushing them is safe.
  Standing *inside* a cluster when it regrows kills you (`kill_if_caught`, at `catch_growth` 0.6,
  about 1.5–2 s after the light leaves). The old "touch kills" `deadly` mode still exists, off by default.
- **Export:** Windows x86_64 + Web export templates being installed (4.7.2). Next step is a Windows
  build into `build/` (git-ignored), run outside the editor, then a draft upload to the jam page.
  Web export needs itch.io settings, still to do. Skip mobile.
- **Placeholder sprites (Oct 27):** the polygon MC is replaced by a sprite cut from the concept
  turnaround (`art/sprites/mc/mc_idle.png`, confirmed working in game). Lamp light now comes from the
  brass lantern on his chest. Guard cut-out ready for Ch 2 (`art/sprites/guard/guard_idle.png`).
- **Art pipeline (decided):** the 3D modeler builds the characters; animations are rendered from a side
  ortho camera to sprite strips + normal maps and replace the placeholders as they arrive. Spec is in
  the "Tunnel Escape — 3D character brief" doc. Sprites drop into `art/sprites/<character>/`.
- **God mode (playtest):** G steps off → 2.5× speed → 5× → off; can't die while on. Works in exported
  builds too; restrict to debug builds before submission.
- **Source control:** this folder is its own git repo, https://github.com/Wasumyon/Tunnel, managed with
  GitHub Desktop. Commit and push after each working change.

## Run
Open `project.godot` and press Play. Main scene: `scenes/chambers/chamber_1.tscn`.

| key | action |
|---|---|
| A / D, ← → | walk (no jump) |
| Space | lamp on / off |
| W / ↑ | hide at a hide spot (Chamber 2+) |
| E | interact (bound, not used yet) |
| R | restart from last checkpoint |
| G | god mode (playtest), can't die: press once 2.5× speed, twice 5×, third time off; shown top-left |

## Built so far
- `scripts/game_manager.gd` — autoload `GameManager`: checkpoint, death → fade → reload, chamber changes.
- `player.tscn` + `scripts/player.gd` — movement, lamp with flicker, hide state, kill(). MC is a static
  placeholder `Sprite2D` (feet at origin, scale 0.5) with a code walk bob, until sprite sheets exist.
- God mode in `GameManager` (`GOD_SPEEDS`, `set_god_level`, label top-left); player reads
  `god_speed_mult` and skips `kill()` while on.
- `scripts/tubeworm_cluster.gd` — procedural tubeworms; retract in light, regrow in the dark;
  `blocks_path` (solid wall while grown), `kill_if_caught` (on: caught inside when they regrow = death),
  `deadly` (off: any touch while grown = death).
- Zones: `hint_zone.gd`, `checkpoint_zone.gd`, `exit_zone.gd`, `hide_zone.gd`.
- `scripts/follow_camera.gd`, `scenes/hud.tscn` (vignette, hint line, message).
- Chamber 1 greybox, generated by `tools/gen_chamber_1.py` (edit in the editor freely after that).

## Physics layers
